# AeroX Voucher

AeroX Voucher is a professional, high-performance Vouch and Reputation System for Discord, designed specifically for AeroX Development.

## Overview

AeroX Voucher tracks positive and negative vouches, maintains a blacklist/DWC (Deal With Caution) list, dynamically synchronizes data with MongoDB, handles profile badges, and automatically verifies members.

## Features

- **Blazing Fast MongoDB Sync:** Seamlessly syncs local in-memory caches to MongoDB Atlas without slowing down bot performance.
- **Vouch Submission & Review:** Users can submit vouches which staff review via a dedicated submission channel.
- **Comprehensive Profile System:** Badges, Top 10 rankings, Server Booster detection, and comment histories all tracked and nicely displayed in user profiles.
- **Scammer / DWC / Blacklist Protection:** Maintain robust control and safety by immediately tracking and alerting users about risky individuals.
- **Dynamic Configuration:** Everything from emojis, staff roles, and branding links is managed efficiently within `config.js`.
